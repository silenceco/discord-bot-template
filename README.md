# 🤖 Discord Bot Boilerplate

A clean, asynchronous Discord bot template built with `discord.py`.

## Features
- Asynchronous execution setup
- Environment variable configuration for sensitive tokens
- Basic command handling & latency check
- Logging configured out of the box

## Quickstart
```bash
pip install discord.py python-dotenv
export DISCORD_TOKEN="YOUR_TOKEN_HERE"
python main.py
